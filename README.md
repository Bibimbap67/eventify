# Eventify

Event management system project.

## Clone the Repository

```bash
git clone https://github.com/Bibimbap67/eventify.git
```

## Open the Project

```bash
cd eventify
```

## Install Dependencies

```bash
npm install
```

## Run the Project

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```

## Quick Setup

```bash
git clone https://github.com/Bibimbap67/eventify.git
cd eventify
npm install

```
